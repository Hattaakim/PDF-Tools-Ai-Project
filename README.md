## OCR output

The searchable-PDF OCR mode renders source pages at up to 3200 pixels per dimension (with a 12-megapixel cap), embeds each rendered page as a PNG, and adds recognized words as transparent PDF text. The visual page remains high-resolution while text can be selected and searched.
